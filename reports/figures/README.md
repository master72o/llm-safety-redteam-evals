# Figures Directory

This directory contains visual charts generated by the Safety Red-Team Evals suite:
- `defense_efficacy_comparison.png`: Bar chart comparing Defense Success Rate and Attack Success Rate (ASR %) across Defenses v0, v1, and v2.
- `vulnerability_by_category.png`: Grouped bar chart displaying ASR per attack category (Prompt Injection, Jailbreak, PII, Harmful Content, System Prompt Extraction).
- `severity_breakdown.png`: Stacked bar chart showing the breakdown of Severity levels (Critical, High, Medium, Low, Safe) across defense variants.
